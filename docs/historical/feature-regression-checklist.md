## Non-Negotiable Preservation Rules
1. All custom Buildroot packages (`nvidia-driver`, `cuda-runtime`, `cudnn-runtime`) MUST remain functional.
2. The custom minimal kernel MUST retain all container and hardware acceleration subsystems (IOMMU, THP, cgroups, namespaces).
3. OpenRC MUST remain the init system.
4. AppArmor profiles and security hardening scripts MUST be fully retained and properly aligned.
5. QEMU direct and EFI boot paths MUST be preserved and consistent.
